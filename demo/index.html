1

Request enters Ingress Controller

TLS termination, rate limiting, and routing rules applied at the nginx ingress. Traffic distributed via round-robin to the service endpoint.

2

Kubernetes Service load-balances to pods

ClusterIP service routes to healthy pods only. Liveness and readiness probes ensure traffic never hits an unready container.

3

FastAPI pod checks Redis cache first

If the exact text was seen recently (within TTL), the cached prediction is returned immediately, sub-5ms response with zero model execution.

4

ONNX Runtime runs DistilBERT inference

For cache misses, the optimised ONNX model runs tokenisation, forward pass, and softmax scoring. Result is written back to Redis with TTL.

5

Prometheus scrapes /api/v1/metrics every 15s

Request counts, latency histograms, model backend type, cache hit ratio, and pod resource usage are all exported as Prometheus metrics.

6

HPA adjusts pod count based on CPU/memory

When average CPU crosses 70%, HPA adds pods (up to 10 max). Scale-down happens after a configurable cooldown window to prevent flapping.

HPA Configuration (from k8s/scalability-config.yaml)

apiVersion: autoscaling/v2
kind: HorizontalPodAutoscaler
spec:
  minReplicas: 2
  maxReplicas: 10
  metrics:
    - type: Resource
      resource:
        name: cpu
        target:
          type: Utilization
          averageUtilization: 70
    - type: Resource
      resource:
        name: memory
        target:
          type: Utilization
          averageUtilization: 80
